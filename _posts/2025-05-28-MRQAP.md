# ❓ What is MR-QAP

**MR-QAP (Multiple Regression Quadratic Assignment Procedure)** is a regression technique used to analyze network data. When applied to the Florida internal migration analysis I am doing, it can answer how well specific relationships between counties explain the connections observed in the actual network. Furthermore, MR-QAP does not simply perform calculations, but also performs permutation tests. 

Following on from the previous analysis, I adjusted the differences in the total population size by county and calculated the percentage of each race to enable comparison of the population composition.

```python
node['White_Ratio'] = node['White'] / node['pop'] * 100
node['Black_Ratio'] = node['Black_African'] / node['pop'] * 100
node['Asian_Ratio'] = node['Asian'] / node['pop'] * 100
```


# 🛠️ Process of MR-QAP

1. To perform MR-QAP analysis, it is first necessary to *convert each network matrix into a vector*. This is a preprocessing step that organizes the data so that regression analysis can be performed on the connections between node pairs within the network.

2. The next step is **OLS regression**. In this process, the equation y = Xβ + ε is used for calculation, and the statistical significance of each coefficient can be evaluated using t-values. Additionally, the R² value of the coefficient of determination can be used to determine how well the entire model explains the dependent variable.

3. Next, I will perform **permutation testing**. In MR-QAP, the observed values are not independent due to the nature of the network structure. To compensate for this, I randomly shuffle the order of the nodes to continuously reconstruct the dependent variable matrix and repeat the same regression analysis each time. By comparing the random regression results obtained in this way with the original regression coefficients, I can evaluate the probability that the results were obtained by chance. Additionally, this process also allows me to validate the p-value.

4. Finally, I compute **permutation p-values**. I compare the distribution of t-values obtained through permutation testing with the actual observed regression coefficients to calculate the p-value. The p-value indicates how often values more extreme than the observed regression coefficient occur randomly. The smaller the p-value, the higher the likelihood that the independent variable significantly explains the dependent variable in the actual network.



# 🧩 Bringing in the Network Data

Additionally, to standardize the sorting order of the matrix, I sorted the county nodes and then converted them into a matrix. This is an important preprocessing step to ensure that all variables are calculated in the same order throughout the subsequent analysis.

```python
dependent_network = nx.to_numpy_array(g, nodelist=ordered_nodes)

```

To evaluate whether the independent variables I will determine later significantly explain migration patterns in future analyses, I also generated randomly generated network matrices. These random matrices serve as a control group and are used to verify the reliability of the analysis results. Each random matrix contains values of 0 or 1, representing random connections between counties. These matrices are added to a list named independent_networks and used in regression analysis alongside the actual variables.

```python
n_random_independent = 2 
independent_networks = []
for i in range(n_random_independent):
    random_adj_matrix = np.random.randint(0, 2, size=(n_nodes, n_nodes))
    random_adj_matrix = np.triu(random_adj_matrix, k=1)
    random_adj_matrix = random_adj_matrix + random_adj_matrix.T
    independent_networks.append(random_adj_matrix)
```



# 📊 Generate independent variable matrix

Next, I created an independent variable matrix to be used in the MR-QAP regression analysis. I created a for loop to calculate the absolute value of the difference between the values of each county pair for the variables used when creating the node data earlier (`income`, `pop`, `Bachelor`, `Master`, `Professional`, `Doctorate`, `White_Ratio`, `Black_Ratio`, `Asian_Ratio`, `degree`) and created a new matrix. The matrices created through each process are saved with the names `var_mat_1` through `var_mat_10` and used as independent variables in the MR-QAP analysis.

## 🔁 For Loop

* The code below is an example of creating a matrix for income.

```python
# initialize an empty matrix for a new network
var_diff_mat = np.zeros((n_nodes, n_nodes))
var = 'income'

# fill the matrix
for i, node1 in enumerate(ordered_nodes):
    for j, node2 in enumerate(ordered_nodes):
        if var in g.nodes[node1] and var in g.nodes[node2]:
            var1 = g.nodes[node1][var]
            var2 = g.nodes[node2][var]
            var_diff = abs(var1 - var2)
            var_diff_mat[i, j] = var_diff
        else:
            var_diff_mat[i, j] = np.nan 
            
var_mat_1 = var_diff_mat
```


## 📏 Calculate distance between counties

The code below calculates the distance matrix between counties. This matrix can be used as one of the independent variables in MR-QAP and is based on the actual geographical distance between two regions. 

```python
# distance to network
county['centroid'] = county.geometry.centroid

# an empty graph
dist = nx.Graph()

# save each polygon as a node and get the centroid as an attribute
for index, row in county.iterrows():
    node_id = row['COUNTYFP'] 
    centroid = row['centroid']
    dist.add_node(node_id, geometry=row['geometry'], centroid=(centroid.x, centroid.y))

# Compute distance between every pair and save it as an edge
all_nodes = list(dist.nodes())
for i in range(len(all_nodes)):
    for j in range(i + 1, len(all_nodes)):
        node1 = all_nodes[i]
        node2 = all_nodes[j]

        centroid1 = Point(dist.nodes[node1]['centroid'])
        centroid2 = Point(dist.nodes[node2]['centroid'])

        distance = centroid1.distance(centroid2)
        dist.add_edge(node1, node2, weight=distance)
```

In the code, GeoPandas is used to calculate the center point of each county, which is then stored as node attributes in a new NetworkX graph. Next, I calculated the Euclidean distance between the center points of all node pairs and assigned weights accordingly. Finally, I converted the results into a numpy array and named it `dist_mat`. This matrix will be used in subsequent analyses to test whether the distance difference between two counties influences migration flows.



# 🤓 MR-QAP Regression Results: Summary and Interpretation

## 🔍 Model Overview

**- Observed R² = 0.0268**
**- Permutation-based R² = 0.0067**

This means that the model explains approximately 2.68% of the overall population movement patterns. Furthermore, this level is statistically significantly higher than the average R² obtained through random permutation.

Looking at the results above, I can see that the variables showing significant results among all variables are `Asian_Ratio`, `Degree`, `Professional`, and `Doctorate`. This indicates that these variables have a significant influence on inter-county migration flows within the model. In particular, the `Doctorate` variable has the strongest explanatory power, with a p-value of 0.0050. Additionally, the coefficient of -0.1017 indicates that a larger gap in the population with doctoral degrees is associated with a decrease in migration flows. On the other hand, the `Asian_Ratio` and `Professional` variables can be interpreted as factors that increase migration flows. This suggests that differences in social structure and educational levels, in addition to simple population size or distance, can influence inter-regional mobility.

## ✅ Conclusion

Through this MR-QAP analysis, I found that social structural variables such as racial composition, educational attainment, and network centrality better explain migration flows than simple indicators such as income or population size. In particular, the increase in migration between counties with similar populations of PhD holders and the association between differences in the proportion of Asian residents and migration suggest the possibility of migration determinants based on social homogeneity or heterogeneity. In future analyses, incorporating additional variables such as housing prices, employment rates, and urbanization levels could further enhance the model's explanatory power.
