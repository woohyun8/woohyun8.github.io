In my previous post, “Internal Migration—Florida Analysis,” I analyzed migration within Florida and created a network. In this post, I will continue with the MR-QAP analysis.

❓ What is **MR-QAP**

**MR-QAP (Multiple Regression Quadratic Assignment Procedure)** is a regression technique used to analyze network data. When applied to the Florida internal migration analysis I am doing, it can answer how well specific relationships between counties explain the connections observed in the actual network. Furthermore, MR-QAP does not simply perform calculations, but also performs permutation tests. 

Following on from the previous analysis, I adjusted the differences in the total population size by county and calculated the percentage of each race to enable comparison of the population composition.

```python
node['White_Ratio'] = node['White'] / node['pop'] * 100
node['Black_Ratio'] = node['Black_African'] / node['pop'] * 100
node['Asian_Ratio'] = node['Asian'] / node['pop'] * 100
```


🛠️ Process of **MR-QAP**

1. To perform MR-QAP analysis, it is first necessary to *convert each network matrix into a vector*. This is a preprocessing step that organizes the data so that regression analysis can be performed on the connections between node pairs within the network.

2. The next step is **OLS regression**. In this process, the equation y = Xβ + ε is used for calculation, and the statistical significance of each coefficient can be evaluated using t-values. Additionally, the R² value of the coefficient of determination can be used to determine how well the entire model explains the dependent variable.

3. Next, I will perform **permutation testing**. In MR-QAP, the observed values are not independent due to the nature of the network structure. To compensate for this, I randomly shuffle the order of the nodes to continuously reconstruct the dependent variable matrix and repeat the same regression analysis each time. By comparing the random regression results obtained in this way with the original regression coefficients, I can evaluate the probability that the results were obtained by chance. Additionally, this process also allows me to validate the p-value.

4. Finally, I compute **permutation p-values**. I compare the distribution of t-values obtained through permutation testing with the actual observed regression coefficients to calculate the p-value. The p-value indicates how often values more extreme than the observed regression coefficient occur randomly. The smaller the p-value, the higher the likelihood that the independent variable significantly explains the dependent variable in the actual network.
