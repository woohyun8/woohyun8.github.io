# Journal Summary

[Kapoor et al. (2024)](https://arxiv.org/abs/2409.15626) served as foundational background for my project, providing key insights into how large language models can enhance topic modeling through semantic clustering, coherence validation, and hierarchical theme extraction.

## 🧐 Research Question & Research Gap

Research Question: **Can combining LLM's context understanding and generation capabilities with existing clustering-based topic modeling generate more consistent and diverse topics than existing techniques?**

In this paper, the authors identify a research gap by stating that “They aren’t without limitations though. BERTopic, for example, is a clustering-based approach which suffers from limitations such as word representation overload or generation of only one topic per text.” To address this limitation, the authors propose a novel method called **QualIT**. It is the *Qualitative Insights Tool* to extend the capabilities of existing topic models. In this paper, the purpose is to generate more nuanced and interpretable topic representations from free-text data. Furthermore, it provide a powerful and scalable approach to automatically identify themes and patterns in large volumes of unstructured text data.

## 🗝️ Method

New method **LLM Enhanced Topic Modeling** consists of multiple steps to generate the main topics, which are then used towards determining sub-topics from documents. There are the three key steps in this approach.

### Step 1) Extract Key-phrases representing the individual document

For the step 1, the LLM prompt can extract multiple key phrases from the document, depending on its content. These key phrases are crucial for realizing the more complex elements of the core topic. 

### Step 2) Hallucination Check

For the next step, the paper progresses the *hallucination check*. It is to ensure the reliability of extracted key phrases, a **Choherence Score**, and it is calculated for each phrase.

This score measures the conformity and applicability of the following subjects by evaluating how effectively the key phrase corresponds with the actual text. In this term, key phrases with the *lowest coherence scores* called **hallucination**.

### Step 3) Clustering

For the final step, **partitional clustering algorithm (K-Means)** used to group the key-phrases identified in the previous step. The purpose of this step is to group documents into multiple clusters, each representing a collection of documents with similar semantic content. In this paper, two layers implied to find the main topics & sub-topics.

**- Clustering for Main Topics**

: Create the primary cluster and pass the key-phrases of each cluster to another LLM prompt -> filter a main theme from the grouped documents

**- Clustering for Sub Topics**

: Uncover more specific sub-topics through implement a secondary level of clustering -> reapply the clustering algorithm to each main cluster

For each sub-cluster, paper did the LLM again to analyze compressed documents with sub-clusters. That is, the model extracts sub-topics, for each sub-cluster.

Furthermore, LLM has several advantages.

i) Reduces noise & the influecne of irrelevant data, allowing the algorithm to operate on the distilled thematic essence of the documents.

ii) Avoid the need for manual data exploration & cleaning steops, such as stopwords or punctuation removal -> able to extract only the most meaningful content from the documents

Furthermore, the equation is estimated using normalized pointwise mutual information, and its range is [-1, 1]. Here, ‘pointwise mutual information’ compares the probability of two words appearing together with the probability of each word appearing individually. The higher the value, the more likely the words appear together. Normalization is performed because the PMI value can become infinite. In this context, values closer to 1 indicate that the two words are semantically well connected.

**Method 2) Topic Diversity**

Topic diversity measures how many different words are used among all topics. Its range is [0,1], where 1 means diversity in topics. 

In the experiments conducted in this paper, each model was evaluated five times using TC and TD with 10, 20, 30, 40, and 50 topics set for each evaluation.

## 1) Preprocess Text Data

```python
import re
# Preprocess the text data
def preprocess_text(text):
    text = re.sub('\s+', ' ', text)  # Remove extra spaces
    text = re.sub('\S*@\S*\s?', '', text)  # Remove emails
    text = re.sub('\'', '', text)  # Remove apostrophes
    text = re.sub('[^a-zA-Z]', ' ', text)  # Remove non-alphabet characters
    text = text.lower()  # Convert to lowercase
    return text
MovTv = movtv2.sample(n=2000, random_state=42)

MovTv['cleaned_text'] = MovTv['text'].apply(preprocess_text)
```

First, I used the above code to remove email addresses, special characters, numbers, and unnecessary spaces from the text, and convert everything to lowercase. After, I stored the results in a new column called **cleaned_text**.

## 2) Tokenize and Remove Stopwords

```python
# Download NLTK stopwords
```


## Hallucination Check

```python
results = []
model = SentenceTransformer("sentence-transformers/paraphrase-MiniLM-L6-v2")

for idx, row in movtv_df.iterrows():
    text = str(row['text'])  # original text or pre-processed text

    # Keywords에서 "Key Phrases:" 제거
    keyphrases_str = str(row['Keywords'])
    if keyphrases_str.lower().startswith("key phrases:"):
        keyphrases_str = keyphrases_str[len("Key Phrases: "):]
    keyphrases = [kp.strip() for kp in keyphrases_str.split(',')]

    # embedding -> convert your original text to numeric vector using 'Transformer'
    
    
    text_embedding = model.encode(text, normalize_embeddings=True)
    kp_embeddings = model.encode(keyphrases, normalize_embeddings=True)
    
    # similarity score -> compare it using cosine similarity

    sims = [np.dot(text_embedding, kp) for kp in kp_embeddings]
    sims_score = np.mean(sims)
    
    # filtering
    valid_kps = [kp for kp, score in zip(keyphrases, sims) if score >= 0.10] # control threshold
    
    # score >= 0.10 : retain the keywords above 0.10

    results.append({
        'original_keyphrases': keyphrases,
        'coherence_score': sims_score,
        'valid_keyphrases': valid_kps, # non- hallucination keyword
    })


results_df = pd.DataFrame(results)
results_df.index = movtv_df.index
movtv_df = pd.concat([movtv_df, results_df[["valid_keyphrases"]]], axis=1)
movtv_df
```

The code above is logic to verify whether the key phrases generated by LLM (GPT) are actually based on the original review text (text column), i.e., whether they were generated without hallucination. I measured semantic similarity using the original review text (text column) as embedding. In this process, the average cosine similarity between each keyword phrase and the original text was defined as the Coherence Score, and only keyword phrases with a score above the threshold (0.10) were classified as **valid keyword phrases**. This also helped improve the accuracy of meaning-based clustering.

## Cluster

```python
def embed_text(text):
    try:
        return model.encode(str(text), normalize_embeddings=True)
    except:
        return np.zeros(model.get_sentence_embedding_dimension())
```

The above code converts the keywords (valid_keyphrases) of each document into sentence embedding vectors. Vectors are numerical representations of the meaning of sentences, which allow us to calculate the distance between different documents. The reason for using **embedding** here is to calculate the semantic similarity between documents.


**Coherence Score: 0.4326**. This score reflects how semantically aligned the extracted key phrases are with the original review text. Since LLMs often rephrase or abstract ideas, token-level similarity tends to be lower than in traditional models, which can result in slightly lower coherence scores.

**Diversity Score: 0.6300**. This score indicates the proportion of unique keywords among all top keywords extracted across clusters.
